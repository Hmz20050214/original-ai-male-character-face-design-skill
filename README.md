# 原创 AI 男角色捏脸 Skill

一套用于设计原创 AI 男性角色面部设定并生成定妆照提示词的 Codex Skill。

它围绕脸型、骨相、三庭五眼、五官主次、年龄感、表情、发型、肤质、服装与影棚光线建立可复用流程，适合 AI 漫剧、短剧、广告、虚拟角色与角色一致性前期设计。

## 能做什么

- 把“帅、清冷、痞帅、成熟、少年感”等抽象气质拆成可执行的视觉变量
- 设计原创男性角色的脸型、骨相、比例与五官主次
- 输出可直接用于生图的完整正向提示词与负面提示词
- 支持胸像特写、半身定妆照、全身白底定妆照与三视图
- 避免明星脸、网红模板脸、过度欧美化与不自然的五官堆叠

## 安装

1. 下载或克隆本仓库。
2. 将整个仓库目录放入 Codex 的个人 Skill 目录：

   ```text
   ~/.codex/skills/original-ai-male-character-face-design/
   ```

3. 确认目录中的入口文件名为 `SKILL.md`，然后重新打开 Codex 会话。

Skill 的标准结构与 `SKILL.md` 元数据格式可参考 [OpenAI 官方文档](https://developers.openai.com/plugins/build/skills)。

## 使用示例

```text
请使用原创 AI 男角色捏脸 Skill，设计一位 27 岁、成熟清冷、理性克制的东亚男性角色，并生成灰底影棚胸像定妆照提示词。
```

也可以只提供简短方向，例如：

```text
设计一个 22 岁、张扬但不油腻的痞帅青年男主。
```

Skill 会根据已有信息补全脸型、比例、五官主次、妆造、构图、光线与负面约束。
